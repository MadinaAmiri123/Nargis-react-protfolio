# Nargis Alizai Portfolio

A responsive React + Vite portfolio with Tailwind CSS v4, Framer Motion page/element animations, React Router navigation, and a persistent light/dark theme toggle.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Build for Netlify

```bash
npm run build
```
Upload the generated `dist` folder to Netlify (Deploys → manual deploy / drag and drop). Build command: `npm run build`; publish directory: `dist` if connecting a Git repository.

## Personalize

In `src/main.jsx`, replace the generic LinkedIn, Instagram and GitHub profile URLs with your personal profile links. Add project cards or a profile photo if desired.
